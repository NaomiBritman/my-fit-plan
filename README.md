# My Fit Plan

A website where a person signs up, enters their details, and gets a personal exercise plan and menu from an AI agent, then tracks them day by day.

The project's main idea is that **AI output is never trusted as is**: every generated plan is validated in code against approved safety limits before anything is shown, and if a check fails, nothing is shown.

> My Fit Plan is not medical advice. It is in active development and currently runs locally in test mode, generating plans only for built-in made-up profiles.

## Features

- Sign up, log in and log out, with hashed passwords and server-side session checks
- Profile with age, height, weight, fitness level and a goal such as weight loss, toning or muscle building
- AI-built one-month demonstration plan with exercises and meals, generated by the Gemini API
- Daily view to tick off exercises and planned meals, plus free-text notes
- History of past days
- Safety module that enforces exercise and nutrition limits on the server and fails closed
- Each person's data is kept separate and checked against the logged-in account
- Responsive design for phones and desktops, in light and dark

## Getting started

Prerequisites: Node.js and npm.

```bash
npm install
cp .env.example .env    # then fill in the values, as explained in the file
npm run db:migrate
npm run dev
```

The site runs on `http://127.0.0.1:3000`. It is limited to this computer on purpose.

A Gemini API key is optional. It is only needed for generating demonstration plans.

## Safety principles

- Progress is gradual, and the site never encourages extreme dieting or overtraining.
- Limit values come only from reliable health sources or a labeled owner decision. None are invented.
- The AI receives only the details a plan needs, never names, emails or passwords.
- No real person's details are sent to the AI provider in the current test mode.
